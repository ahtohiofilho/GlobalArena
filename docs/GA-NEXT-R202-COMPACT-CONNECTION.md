# R202 — Compact Connection

R201 approved 3/3 at 2723ff3. Connection has a bounded scrollable body with persistent header and a smaller initial footprint (440 x 410 logical pixels). Current freight, tariff, active capital and pending funding use decimal units. Only unactivated construction projects appear in the construction section; activated history remains untouched in the kernel. The workforce section is relevant only for an unfinished owned project. Funding inputs are hidden while a project is active; in construction mode cancellation is shown only for a pending order. The existing legacy smoke retains both investment buttons. The scene smoke asserts absence of empty-project progress and retains exact amount/queue/cancel checks. Visual acceptance must verify idle, funded, partial, completed and subsequent-turn states and scrolling with many workers. No changes to economy, worker scheduling, navigation or canonical state.
