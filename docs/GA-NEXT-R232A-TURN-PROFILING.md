# R232A — Turn profiling baseline

Base #683 b9bcce3: two workflows passed, site colors and real transit acceptance verified. User reported turn latency increasing on a Windows Debug playtest at turn 100. Measure before optimizing.

Explicit opt-in GA_NEXT_R232_TURN_PROFILE=1 opens a synchronous thread-local sampling session during the real E handler. Disabled by default. Uses Stopwatch timestamps and managed bytes allocated on the calling thread, records inclusive elapsed microseconds, call count and allocation bytes by phase. Instrument real persistent host close, worker calendar, automatic allocation, journal staging, economic derivation, financial reconciliation, market distribution, accounting, demographic close, independent replay, canonical hashing, trade publication, synchronous UI attach and refresh, and overall E handler. Nested measurements overlap and must not be summed; allocation bytes are not live heap/RSS, and GPU or later async frame costs are not included. Profiling is observational and never an input to simulation, event, RNG, or state. No algorithm changes, extra market solve or reduced replay. Log aggregate census, occupied nodes, participant-visible edge count and committed hash only in explicit diagnostic mode.

CI continues the existing uniform-city real E-close scenario: nine stationary turns, one all-human crossing with skipped birth, one arrival, then stationary closes through cycle 50 (101 workers total). GA_NEXT_R232_PROFILE_THROUGH_CYCLE can select 12–1000 for this explicit smoke. Every close retains replay, census and authorized publication checks; require all key phase sample lines for each close. Use a 600s safety timeout, no machine-specific latency threshold. Logs retained in existing artifact. This establishes a low-site-count Debug/headless Ubuntu baseline, not a claim about distributed-world scaling, Windows or Release. Subsequent increments should compare dispersed sites, 100+ cycles, Release vs Debug and representative Windows timings, then target measured bottlenecks with exact equivalence tests.
