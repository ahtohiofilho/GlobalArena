# R223.1 — Canonical base activity value

Optional immutable BaseActivity on the existing canonical per-worker queue, separate from finite Orders and actual worker activity. Null preserves legacy behavior and hash formats; explicit owner-authorized SetBaseActivity transitions to format 23, with worker-ordered canonical encoding (tag 50). Manual supports existing agricultural, forestry, mining and land/port roles; optional crop 1–6 only for agriculture. Automatic has no manual payload and no implemented selection algorithm. No new resource catalog. Legacy queues with any indefinite occupation order reject conversion until explicit migration is designed; base-enabled queues reject new Occupation entries. Queue edits and lifecycle preserve the preference, including ordinary world copies. Newborn queues remain legacy/unconfigured; no birth activation. Journal SetBaseActivity has distinct payload validation and independent hash replay. No UI, scheduler, private collective plan integration or economic activation in this revision; do not expose the command in gameplay yet. R223.2 must integrate actual finite completion, time residual, base occupation, crop output, and pending command publication, and define migration/init/invalid-location behavior before activation.
