# R223.2 — Manual base scheduling

Opt-in canonical manual base preference is resolved when no finite task or frozen crossing remains. The scheduler reuses signed geography and the same agricultural policy as settlement. Actual residual slices carry the selected crop or occupation, and existing market, demand, food and operational freight projection consume those slices. Exact-boundary completion restores base readiness without inventing a productive slice. Legacy queues without a base retain their prior behavior. No automatic revenue optimization; unresolved automatic policies and explicit crops without policy fail closed. Provisional eligibility: land only, explicit crops require positive local output; incompatible nodes retain preference and idle. Noncrop goods still use existing worker production profile, not a new resource catalog. Blocked finite tasks retain existing waiting behavior. Team rounding may leave a one-micro idle interval, unchanged. Collective phase accepts journal base edits; private human staging and UI are not yet integrated. No production activation, newborn policy, implicit migration or final balance. New tests cover 0.6 construction + 0.4 rice, next full turn and replay; 0.6 construction + 0.4 land logistics and opening freight. Further tests for travel, multiple finite tasks, exact boundary, invalid location and port remain outstanding. R221.4 carryover remains open. CI pending; no merge.
