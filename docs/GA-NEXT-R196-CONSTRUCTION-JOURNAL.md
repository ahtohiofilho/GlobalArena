# R196 — Collective construction journal

R195 approved 9/9. Opt-in signed-world host accepts an explicit construction conversion rate and initialized construction ledger. The existing monetary orders become funded events. Human work orders target already funded projects; one batch per turn validates ownership, physical location, exclusive worker allocation and neutral productivity, recomputes receipts and automatically commissions completed projects. A fresh replay executor independently verifies the batch and rejects duplicate or competing worker events. The host exposes funding and work events in its receipt and compares canonical replay hashes.

The current opt-in mode intentionally excludes economic settlement: applying new freight to all earlier production in the same turn would violate the completion-time rule. Legacy host behavior remains unchanged. Next gates integrate economic settlement timing, construction order UI, persistence encoding and eventually generic editable worker queues. Residual Work is recorded but not automatically used yet. Explicit construction orders are per turn, not persistent assignments. No claim of visual or CI approval before evidence.
