# R208 — Atomic construction funding and worker intentions

R207 approved 11/11 at 9ef945b. One immutable journal transaction invokes existing construction funding admission and debits real treasury once, obtains the actual canonical project ID, inserts Build intentions into selected owned worker queues at explicit indices and verifies before/after hashes. Worker IDs are sorted deterministically, duplicates rejected; zero selected workers is valid. Remote and occupied workers may be scheduled; no instant travel or work. Invalid assignments reject the entire transaction without publishing intermediate states. Existing queue entries are preserved. No new construction price or work-rate policy. This increment is an executable isolated journal boundary, not yet installed in the interactive host or collective turn publisher. Subsequent cutover must integrate automatic travel, head lifecycle, explicit interruption, residual time and economic demand slices; no duplicate debit. Dedicated CI and regression tests pending.
